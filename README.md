Compare Riemann Zero Statistics with Random Matrix Theory

The nontrivial zeros: ζ( 1/2+iγ_n )=0

appear to have the same spacing statistics as eigenvalues of random Hermitian matrices from the Gaussian Unitary Ensemble (GUE).

This was first observed by Hugh Montgomery and famously discussed with Freeman Dyson.
